# X806 Cross-Platform Rust Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cross-platform Rust workspace (`x806-core`, `x806-cli`, `x806-gui`) that provides full hardware feature parity with `X806.exe` on Linux, macOS, and Windows for the X806 8-key macro keypad (`VID 0x30FA / PID 0x1340`).

**Architecture:** A pure-Rust core library (`x806-core`) owns the data model, VK↔HID tables, `config.ini`/`macroGrp.ini`/`.dat`/TOML codecs, deterministic EEPROM compiler, and `HidTransport` abstraction (`hidapi` + `MockTransport`). Both a scriptable CLI (`x806-cli`) and a native `eframe`/`egui` 4-tab desktop configurator (`x806-gui`) sit cleanly on top of `x806-core` with zero protocol duplication.

**Tech Stack:** Rust (`rustc 1.99.0`, `cargo 1.99.0`, edition 2024), `hidapi` (`linux-native` pure-Rust `hidraw` on Linux, native HID on Windows/macOS), `eframe`/`egui`, `clap`, `serde`, `toml`, `base64`, `thiserror`, `directories`, `rfd`.

**Spec:** [2026-11-21-x806-rust-suite-design.md](../specs/2026-11-21-x806-rust-suite-design.md) and [protocol-spec.md](../../protocol-spec.md).

## Global Constraints

- **Hardware target:** `VID = 0x30FA`, `PID = 0x1340`; control collection `UsagePage = 0xFF01`, `Usage = 0x0001`, Report ID `0x07` (8 bytes); event collection `UsagePage = 0xFF00`, `Usage = 0x0001`, Report ID `0x06` (3 bytes).
- **EEPROM safety:** Never write `0x0000` or `0x0002..0x0007`; always RMW `0x0076` preserving bits `7:2`; always validate compiled macro size against `macro_limit` (`0x07F8` or `0x0FF8`) before writing any byte; always enforce protocol timings (`4 ms` stage->commit, `2 ms` commit->idle, `20 ms` apply->idle).
- **Platform parity:** Pure-Rust `hidapi` (`linux-native`) on Linux with bundled `udev/99-x806.rules`; no admin/root required; omit Windows-only `DPI_SPEED`/`WHEEL_SPEED` OS calls (preserve in `config.ini` round-trip only).
- **Key & color fidelity:** Active-low 4-bit RGB channels (`0` = full ON, `15` = OFF); active LED cycle speed clamped to `0..=6` (`7` reserved for `Mute`); `VK_OEM_3` (`0xC0`) maps to HID `0x35`.
- **Commits:** Conventional Commits (`feat`, `fix`, `docs`, `test`, `chore`, etc.), lowercase only, imperative mood, subject `< 50` chars.

## Review Focus

1. **Malformed or quirk-heavy legacy files (`config.ini`, `macroGrp.ini`, `.dat`):** Inline `//` comments, mixed `\r\n`/`\n`/`\r`, duplicate keys between `[Config0]` and `[ShareData]`, `PUBG_CN.dat` lines padded past `1,861` bytes, UTF-16LE BOM `macroGrp.ini`, and invalid `ISD=1` Base64 must parse cleanly or return typed `X806Error` without panicking. *(Pinned in Task 2.)*
2. **EEPROM safety & overflow boundaries:** Macro bytecode exceeding `0x07F8` (2 KB) or `0x0FF8` (4 KB) must fail with `X806Error::MacroOverflow` before any HID write; every emitted write operation must satisfy `addr == 0x0001 || addr >= 0x0008`. *(Pinned in Task 3.)*
3. **Delay quantization & splitting boundaries:** `delay_ms = 0`, `delay_ms > 10000`, exact multiples of `127 * polling_ms` (e.g., `254 ms` at `1000 Hz`), and all 4 polling rates (`125/250/500/1000 Hz`) must never emit 0-tick packets and must keep descriptor `step_count` equal to emitted packets. *(Pinned in Task 3.)*
4. **Disconnected / multi-collection HID handling:** Opening the device must filter strictly on `VID 0x30FA`, `PID 0x1340`, `UsagePage 0xFF01`, `Usage 0x0001` (ignoring mouse/keyboard/consumer collections), return `X806Error::DeviceNotFound` when absent, and propagate mid-transfer I/O errors cleanly. *(Pinned in Task 4.)*
5. **GUI macro recorder & input boundaries:** Held-key typematic auto-repeat must be deduplicated, orphan key-ups ignored, recordings capped cleanly at `110` events (`55` key-downs), macro names clamped to `30` UTF-16 code units, and active LED speed clamped to `0..=6`. *(Pinned in Task 6.)*

## File Structure

- `Cargo.toml` — Workspace manifest defining `crates/x806-core`, `crates/x806-cli`, `crates/x806-gui` and shared workspace dependencies.
- `udev/99-x806.rules` — Linux `hidraw` udev rule (`idVendor=="30fa"`, `idProduct=="1340"`).
- `README.md` — Build, Linux udev installation, CLI, and GUI usage guide.
- `crates/x806-core/src/`:
  - `lib.rs` — Public re-exports and hardware constants (`VID`, `PID`, `USAGE_PAGE_CONTROL`, `USAGE_PAGE_EVENT`).
  - `error.rs` — `X806Error` enum (`thiserror`).
  - `keycode.rs` — USB HID Usage ID ↔ Windows VK ↔ display names (including mouse pseudo-VKs `0xF0..0xF2` ↔ `0xF1/0xF3/0xF2`).
  - `model.rs` — Serializable domain types (`DeviceConfig`, `ProfileConfig`, `KeyAction`, `MediaKey`, `BuiltinShortcut`, `Macro`, `MacroEvent`, `RepeatMode`, `LedConfig`, `LedMode`, `Rgb4`, `PollingRate`).
  - `defaults.rs` — Factory default `DeviceConfig` (`keys 1..8 = HID '1'..'8'`, `KEYMAP = [7,3,2,1,9,6,5,4]`, `Cycle breath`, `500 Hz`) and the 8 built-in shortcuts matching `constMacro.dat`.
  - `codec/{mod.rs,dat.rs,ini.rs,toml.rs}` — `.dat` (v3, legacy, `ISD=1` Base64), `config.ini` + `macroGrp.ini` (UTF-16LE BOM), and native TOML codecs.
  - `eeprom.rs` — Pure compiler producing `EepromPlan` (`Vec<EepromWrite>`, `macro_bytes_used`) from `DeviceConfig`, `MacroLibrary`, `hw_flags`, `existing_0x76`, and `macro_limit`.
  - `hid.rs` — `HidTransport` trait, `MockTransport`, `HidApiTransport`, `DeviceStatus`, `X806Device<T>` high-level read/flash API.
- `crates/x806-cli/src/main.rs` — `x806` binary (`status`, `apply`, `reset`, `import`, `export`, `macro inspect`, `udev`).
- `crates/x806-gui/src/`:
  - `main.rs` — Native `eframe` entrypoint.
  - `keymap.rs` — `egui::Key` + modifiers ↔ USB HID Usage ID mapping.
  - `recorder.rs` — Pure, unit-tested `MacroRecorder` state machine (no GUI runtime dependency).
  - `app.rs` — `X806App` state, top tab bar, hardware status/refresh, bottom profile & action bar (`Game I/II/III`, `Import`, `Export`, `Reset`, `Apply`, `Cancel`), local TOML persistence.
  - `tabs/{mod.rs,base.rs,macro_tab.rs,advanced.rs,led.rs}` — The 4 UI tabs.
